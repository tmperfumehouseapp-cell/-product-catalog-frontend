# Deploy: redesigned home page

Files: `index.html`, `theme.css`, `index-classic.html` (the previous home page).

1. Hostinger > Websites > customer site > File Manager, open the folder that contains `products.html`.
2. Download the current `index.html` as a backup.
3. Upload `index.html`, `theme.css` and `index-classic.html`, overwriting when asked.
4. Open the site on a phone, hard refresh, check products, categories and search.
5. Rollback: upload the backed-up `index.html` (or rename `index-classic.html` to `index.html`).
